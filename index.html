Video / concept workflow

1. Learn the data structure

Understand operations, invariants and complexity before attempting pattern problems.

2. Learn one base pattern

Watch one focused explanation only if your own derivation fails. Pause before the code and predict the next step.

3. Solve the base problem

Use a 25–40 minute attempt window for a medium. Write brute force, identify the bottleneck, then optimize.

4. Derive variations

Change one constraint: sorted vs unsorted, exact vs at-most, one query vs many, static vs dynamic updates.

5. Retrieve from memory

Redo on +1, +3, +7, +14. If you need a hint, mark the review as struggled and reset the schedule.

Setup guide

  1. Create a free Supabase project and copy the Project URL and anon/publishable key.
  2. Open the included supabase-setup.sql in Supabase SQL Editor and run it.
  3. Host index.html on GitHub Pages or another static host.
  4. Open the hosted URL on each device, enter the same Supabase URL/key, then sign in with the same account.
  5. For production-grade use, enable email confirmation in Supabase. If confirmation is enabled, follow the email verification link before signing in.
  6. To enable the AI coach, deploy supabase/functions/dsa-ai-coach/index.ts using the Supabase CLI, set OPENAI_API_KEY, then restrict usage with AI_ALLOWED_USER_ID set to your own Supabase Auth user UUID. Read README.md for exact commands.

Cloud sync requires the database setup and authentication. AI also requires the Edge Function and a server-side OpenAI API key. API usage may cost extra. Never place a private AI key in this HTML file.
